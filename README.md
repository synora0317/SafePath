# SafePath — 재난안전 AI 대피 안내

재난 상황에서 **사용자의 조건(이동수단·동행자·기관 유형)에 맞는 대피소와 이동 경로**를 추천하는 Streamlit 웹앱입니다.
같은 재난이라도 휠체어 사용자, 반려동물 동반자, 병원·요양시설은 갈 수 있는 대피소가 다르다는 문제에서 출발했습니다.

> 🔗 데모: (배포 후 링크 추가 — 예: https://safepath.streamlit.app)

## 주요 기능

### 1. 개인 모드
위치 → 재난 유형 → 이동수단 → 동행자 순서로 입력하면 개인 맞춤 안내문 1개를 출력합니다.

| 입력 | 선택지 |
|---|---|
| 현재 위치 | 서울 중구·종로 일대 16개 동 |
| 재난 유형 | 호우 / 태풍 / 대설 / 산불 / 지진 |
| 이동수단 | 도보 / 차량 / 휠체어 |
| 동행자 | 없음 / 어린이 / 노약자 / 반려동물 |

- **휠체어** 선택 시 교통약자로 자동 분류 → 경사로·엘리베이터가 있는 대피소만 추천
- **반려동물** 동반 시 → 반려동물 동반 가능 대피소만 추천

### 2. 기관 모드
병원, 요양시설, 학교, 어린이집, 장애인시설, 공장 등 **단체 대피가 필요한 기관**을 위한 조치사항을 5개 항목으로 출력합니다.

1. 현재 재난 위험도
2. 기관 주변 위험 요소
3. 추천 대피소 및 추천 이유
4. 단체 이동 경로 및 이동 시 주의사항
5. 대피소 운영 상태 (잔여 수용 인원, 개방 여부)

- **병원** → 의료 지원이 가능한 대피소만 추천
- **병원·요양시설·장애인시설** → 교통약자 접근성이 있는 대피소만 추천

### 3. 위험 단계 자동 판정
사용자가 위험 단계를 고르지 않고, **AWS(자동기상관측) 관측값을 재난 시나리오 임계값과 비교**해 자동으로 정합니다.

- 호우: 관측 강수량(mm) 기준
- 태풍: 관측 풍속(m/s) 기준
- 산불: 관측 풍속을 산불 시나리오의 대피 권고 단계와 매칭
- 대설·지진: 관련 실시간 관측 데이터가 없어 기본값(관심 단계)으로 표시하고, 안내문에 데이터 한계를 명시

### 4. 지도와 경로
- folium 지도에 현재 위치·대피소 마커와 경로선 표시
- OSRM으로 실제 도보 경로를 조회하고, 조회에 실패하면 직선 경로로 자동 대체

## 사용 기술

| 구분 | 기술 |
|---|---|
| 언어 | Python |
| 화면 | Streamlit |
| 지도 | folium |
| 경로 탐색 | OSRM (공개 데모 서버) |
| 판단 로직 | 규칙 기반 위험도·필터링 엔진 (`risk_engine.py`) |

### 내장 데이터
별도 데이터 파일이나 API 키 없이 실행되도록 `data.py`에 데모용 데이터를 내장했습니다.

- 개인 30명, 시설 20곳
- 대피소 32곳 (의료 지원·교통약자 접근성·반려동물 동반 여부 포함)
- AWS 관측소 27곳, 재난 시나리오

## 폴더 구조

```
SafePath/
├── app.py             # 화면 구성과 입력 흐름
├── data.py            # 내장 데이터 (위치·시설·대피소·관측소·시나리오)
├── risk_engine.py     # 위험도 판정과 대피소 필터링 규칙
├── ui_components.py   # 추천 대피소 카드 UI
├── theme.py           # 색상·폰트·전역 CSS
├── map_view.py        # folium 지도 (마커 + 경로선)
├── routing.py         # OSRM 도보 경로 조회 (실패 시 직선 대체)
└── requirements.txt
```

설계할 때 **화면(app.py), 데이터(data.py), 판단 로직(risk_engine.py)을 분리**해서, 대피소 조건이나 위험 기준을 바꿀 때 한 파일만 수정하면 되도록 했습니다.

## 실행 방법

```bash
python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

경로선 조회에는 인터넷 연결이 필요합니다. 연결이 없으면 직선 경로로 표시됩니다.

---

## 한계와 개선 방향

- 내장된 관측값이 평온한 날 기준이라 대부분 '관심' 단계로 판정됩니다. 실시간 기상청 API 연동이 다음 단계입니다.
- 산불은 풍속만 반영하며, 실효습도 등 다른 확산 요인은 실시간 데이터가 없어 반영하지 못했습니다.
- 대피소 잔여 수용 인원은 데모 데이터이며, 실제 운영 데이터와 연동이 필요합니다.
- 대상 지역이 서울 중구·종로 16개 동으로 한정되어 있습니다.
